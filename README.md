# brfcktoc: Yet another Brainf*ck to C transpiler 🗿

This programs translates given source code of the Brainf*ck esolanguage into its equivalent source code in C.

## Compile from source 🛠️
Requirements:
1. C compiler (gcc, clang, ...)
2. GNU Make

Open the containing folder in a terminal and run `make`.

## Usage
```bash
./brfcktoc path/to/source -o path/to/target
# or
./brfcktoc path/to/source
```
